WrongGPU FSR front end: third-party notices
===========================================

WrongGPU's DLLs (amd_fidelityfx_dx12.dll, ffx_fsr3_x64.dll, ffx_fsr3upscaler_x64.dll) contain no third-party code.
At build time they use type declarations (structures, constants, function signatures) from AMD's FidelityFX SDK API
headers, which are MIT-licensed:

- FidelityFX SDK 1.1.4, FidelityFX API headers (ffx_api.h, ffx_api_types.h, ffx_upscale.h, ffx_framegeneration.h),
  https://github.com/GPUOpen-LibrariesAndSDKs/FidelityFX-SDK
- FidelityFX SDK fsr3-v3.0.4, FSR 3.0 host headers (structure layouts checked at build time only),
  https://github.com/GPUOpen-LibrariesAndSDKs/FidelityFX-SDK

AMD's own FidelityFX DLLs that ship with a game stay in the game folder (renamed *.wronggpu-original.dll) and are
neither modified nor redistributed by WrongGPU.
